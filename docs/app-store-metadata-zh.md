## 4. 完整描述

TodoCa 是面向加拿大登陆前后用户的任务管理、英文场景和生活资源工具。

完成简短的入门设置后，TodoCa 会根据你的身份、预计登陆日期和家庭情况，在设备上生成适合你的任务清单。你可以完成、跳过或撤销任务，查看总体进度，并在下次打开时继续使用。

主要功能：

- 按登陆阶段整理的个性化任务清单
- 每项任务的材料、步骤、完成标准和官方来源
- 常见办事场景的中英文脚本及一键复制
- 温哥华生活资源、地址、电话、官网和 Google Maps 外链
- 在需要时主动提交中文人工协助请求

用户画像和任务进度默认只保存在当前设备。TodoCa 目前不要求注册，不提供云同步，也没有付费墙或应用内购买。

重要说明：TodoCa 提供任务管理、信息整理和生活资源导航，不提供法律意见，不提供持牌移民顾问服务，不代表加拿大政府或任何官方机构，也不保证签证、工签、学签、永久居民或其他申请结果。政策和资源信息可能变化，请通过加拿大政府及相关机构的官方来源核实重要信息。
