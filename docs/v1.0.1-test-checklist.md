# TodoCa V1.0.1 验收清单

## Windows / Web 可完成

- [ ] `npm run lint` 通过。
- [ ] `npm run build` 静态导出通过。
- [ ] `npm run cap:sync` 成功，Preferences 出现在 iOS Package Dependencies，生成的 Swift 本地包路径使用 `/`。
- [ ] 新用户完成 onboarding 后，刷新页面仍保留画像和进度。
- [ ] V1 localStorage 只有旧键时，启动后生成 `CapacitorStorage.*` 新键且数据一致。
- [ ] 新存储已有合法数据时，以新存储为准，并回写旧键。
- [ ] 新存储 JSON 损坏、旧存储合法时，可以从旧存储恢复且不白屏。
- [ ] 重复刷新和重复迁移不会丢失或重复任务进度。
- [ ] “清除所有数据”后新旧画像、进度和迁移版本键均被清除。
- [ ] 任务与资源详情的纠错入口携带正确内容 ID 和标题。
- [ ] 无 Supabase 配置时，纠错表单明确显示“仅保存在此设备，尚未发送”。

## Mac / Xcode 必须完成

- [ ] 用安装了 App Store 1.0 的真机制造画像和至少三个不同任务状态。
- [ ] 覆盖安装 1.0.1 Build 2，确认画像和所有任务状态保留。
- [ ] 强制退出并重开 App，确认数据仍在。
- [ ] 修改、完成、撤销任务后再次重开，确认新数据仍在。
- [ ] 验证 `PrivacyInfo.xcprivacy` 被 App target 打包，Archive 隐私清单无警告。
- [ ] 联网提交一条任务纠错和一条资源纠错，在 Supabase 确认 `related_task_id` 与描述标签正确。
- [ ] 断网提交纠错，确认不会误称已经发送。
- [ ] 卸载后重装，确认应用按隐私说明从空白状态开始。
