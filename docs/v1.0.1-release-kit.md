# TodoCa V1.0.1 发布与宣传素材

## App Store 版本说明

本次更新提升了任务进度的本地保存可靠性，并新增信息纠错入口。如果你发现政策、地址、电话或办事链接已经变化，可以直接在对应页面告诉我们。我们也修正了若干文字和使用体验问题。

## App Review Notes 增量说明

- Version: 1.0.1 (Build 2)
- 用户画像和任务进度现通过 Capacitor Preferences（iOS UserDefaults）保存在设备本地。
- 首次升级会自动读取 1.0 的本地 Web 存储并迁移；不上传画像或任务进度。
- 任务和资源详情新增内容纠错入口，复用现有 `service_leads` 提交流程。
- App 仍无需登录，没有付费墙、订阅或应用内购买。

### 正文

TodoCa 上线后的第一个小更新来了。

这次没有急着堆新功能，先做了两件更基础的事：

1. 提升任务进度在 iPhone 本地保存的可靠性，旧版数据会自动迁移。
2. 每个任务和生活资源页面都增加了“发现信息有误或已经过期”。政策、地址、电话和官网发生变化时，可以直接告诉我是哪一条。

TodoCa 是一份面向加拿大登陆前后 6 个月的中文任务清单，目前先从温哥华版开始。它不会替代政府或专业人士，但希望帮你少漏一件事、少走一点弯路。

如果你已经在用，欢迎告诉我：哪一条任务最有帮助，哪一条最需要更新？
